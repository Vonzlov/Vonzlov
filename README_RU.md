Делаю инструменты на LLM для реальных бизнес-процессов: ассистентов внутри привычного людям софта, автоматизацию рутинных задач и конвейеры, которые превращают обычный текст в готовые документы.

## Проекты

### [pptx-telegram-bot](https://github.com/Vonzlov/pptx-telegram-bot) &nbsp; ![стабильно](https://img.shields.io/badge/%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81-%D1%81%D1%82%D0%B0%D0%B1%D0%B8%D0%BB%D1%8C%D0%BD%D0%BE-2ea44f?style=flat-square)

Telegram-бот, который превращает обычный текст в готовую презентацию `.pptx` в корпоративном шаблоне. Любой шаблон подключается через YAML-конфиг, без правок кода.

**Стек:** Python, aiogram, python-pptx, pydantic, Ollama (опционально), Docker, pytest

### [llm-bench](https://github.com/Vonzlov/llm-bench) &nbsp; ![в разработке](https://img.shields.io/badge/%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81-%D0%B2%20%D1%80%D0%B0%D0%B7%D1%80%D0%B0%D0%B1%D0%BE%D1%82%D0%BA%D0%B5-d29922?style=flat-square)

Сервис-бенчмарк для выбора LLM под конкретную задачу: прогоняет один и тот же набор задач через локальные модели и облачные API и сравнивает результаты.

**Стек:** Python, Ollama, vLLM, облачные LLM API, Docker, k3s, kind

### [pqc-scout](https://github.com/Vonzlov/pqc-scout) &nbsp; ![ранняя стадия](https://img.shields.io/badge/%D1%81%D1%82%D0%B0%D1%82%D1%83%D1%81-%D1%80%D0%B0%D0%BD%D0%BD%D1%8F%D1%8F%20%D1%81%D1%82%D0%B0%D0%B4%D0%B8%D1%8F-8b949e?style=flat-square)

Ассистент для миграции кода на постквантовую криптографию: находит в кодовой базе алгоритмы, уязвимые для квантовых атак, и помогает спланировать их замену.

**Стек:** Python, LLM

### Рабочие проекты (закрытый код)

**HR-ассистент в Outlook.** Три кнопки на ленте: черновик ответа на выбранное письмо, доработка черновика по комментариям пользователя, сводка по всей переписке. VBA поверх API корпоративной LLM.

**Автоматизация процессов.** Воркфлоу в n8n, которые рассылают участникам проектов дайджесты их задач, и VBA-макросы для ежемесячного расчёта премий и карт КПЭ.

### Небольшие проекты

**Подбор вакансий.** Telegram-бот на n8n, который собирает вакансии с hh.ru и отбирает подходящие под мой профиль.

**Озвучка текста.** Telegram-бот, который озвучивает текст через сторонний TTS API.

## Стек

- **Языки:** Python, JavaScript, SQL, VBA
- **LLM:** OpenAI-совместимые API, Ollama, vLLM, LLM-агенты, RAG, промпт-инжиниринг, оценка LLM
- **Автоматизация:** n8n, Telegram-боты (aiogram), RPA (PIX), Bubble.io
- **Инфраструктура:** Docker, k3s, Kubernetes (kind), Git, Linux

## Как я работаю

- **Простота важнее изящества.** Прямолинейный код, который следующий человек прочитает и сможет поддерживать, даже ценой дублирования.
- **Надёжность в первую очередь.** Инструмент, встроенный в чужую работу, не падает на неожиданных данных, а пропускает или помечает то, что не смог обработать.
- **Сначала замеры, потом выбор.** Модель выбираю по тестам на реальной задаче, а не по репутации.
